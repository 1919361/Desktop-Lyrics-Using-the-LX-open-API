# LX Music 桌面歌词 · Wallpaper Engine

> **版本 1.2.0** ｜ 依赖 [LX Music](https://github.com/lyswhut/lx-music-desktop) 的开放 API

> 创意工坊：<https://steamcommunity.com/sharedfiles/filedetails/?id=3805744669>

![预览](preview.jpg)

一个把 LX Music 的播放状态变成桌面壁纸的项目：左半屏是 Apple Music 风格的播放区，
右半屏是逐字扫光、对唱同步、带翻译的歌词列，背景由专辑封面取色实时生成。

## 功能

**画面**

- 屏幕按中线分左右两半：**左 = 播放区**（封面 → 歌名/歌手 → 进度条 → 控件行，全左对齐同一条竖线），**右 = 歌词列**
- 封面是视觉主体：取色后驱动 WebGL 背景，铺成 Apple Music 式四色渐变 + fBm 云雾，流动速度与亮度由**真实低频能量**驱动
- 换歌时封面绕竖直中线**翻页**（旧封面转出去、新封面转回来，两段非线性缓动）
- **天际屏**：当前句的单个字放大漂浮在背景上（间奏时换成音符），层级在背景/封面之上、歌词之下
- 液态玻璃已移除：控件行是纯图标，没有任何底板/描边/背景滤镜

**歌词**

- 支持 Any Listen 逐字格式与标准 LRC；逐字扫光 + 抬字，`当前字` 带强调色光晕
- 同刻对唱（两句时间戳几乎相同）**同时扫光**，滚动与放大对齐"唱得最久"的那句
- 翻译歌词挂在当前句下方，左缘与主歌词对齐
- 间奏等待点 `· · ·`：进入间奏才展开、逐颗点亮、整体呼吸、结束前缓动涨大再收回
- **唱完的句子**：缩小 + 模糊，同时一道删除线从左划到右，线到尽头时整行淡出隐藏
- **最后一句**唱完不收起，保持高亮
- 空歌词显示「没有歌词」；只有一句的占位词（如「纯音乐，请欣赏」）照常显示
- 切换歌曲用 `[ti:]`/`[ar:]` 做归属校验，避免串台；洛雪仍返回上一首歌词时会清屏并继续重试

**播放与交互**

- 进度条可点击/拖动定位（9px 粗，无圆点滑块）；拖动时整屏歌词与时间跟着预览走，松手才提交
- 音量条拖动**实时下发**（节流约 90ms），不等到松手
- 上一首 / 播放暂停 / 下一首 / 收藏 / 静音，全部纯图标
- 本地播放时钟平滑推进，权威进度只做"速度微调"，不会因轮询抖动；能识别曲尾自动切歌并冻结旧歌词
- 连接状态小条显示协议、地址、端口与连接结果（可关）

## 环境要求

| 项目 | 说明 |
|---|---|
| **LX Music** | 必须。需在设置里启用「开放 API」服务 |
| **Wallpaper Engine** | 网页类型壁纸，建议较新版本（用到 `aspect-ratio`、WAAPI 等较新的 Web 特性） |
| 自定义字体（可选） | 把字体文件命名为 `CustomFont.ttf` 或 `CustomFont.otf` 放进工程目录即可（优先于面板里的字体列表；请自备授权） |

LX Music 默认监听 `127.0.0.1:23330`；改了端口就在壁纸属性「LX Music 开放 API」里同步修改。

## 快速开始

**1. 开启 LX Music 的开放 API**

LX Music →「设置」→「其他」→ 打开「开放 API」。默认地址 `127.0.0.1:23330`。

**2. 导入 Wallpaper Engine**

打开 WE → 壁纸编辑器 → 创建壁纸 → 选择本工程目录下的 `index.html`（WE 会自动勾选它引用的文件）→ 保存。

> `tools/` 里是开发/自测脚本，WE 不会引用它，也不影响运行；要发布精简版可以整个目录移走。

**3. 播放音乐**

在 LX Music 里播放任意歌曲，壁纸会自动连上并开始滚动歌词。

> WE 不会自动刷新已加载的网页壁纸：改完文件后右键托盘图标 →「重新载入壁纸」才会生效。

## 属性面板

共 **42 项**：6 个分组下的 41 项，外加 1 项全局「强调色」。

### 强调色

| 项 | 说明 |
|---|---|
| 强调色 | 当前字的光晕、音频律动的颜色来源 |

### 背景图片

| 项 | 说明 |
|---|---|
| 使用背景图片 / 自定义背景图 | 选图后作为整屏氛围底图（轻微模糊 + 压暗 + 暗角） |
| 亮度 / 对比度 / 饱和度 / 模糊 / 缩放 / 对齐 | 照片的调色与构图 |
| 压暗 / 暗角 | 0 = 完全不压暗；越大白字越压得住浅色照片 |

### 背景律动与氛围

| 项 | 说明 |
|---|---|
| 背景律动强度 | 动态背景（四色渐变 + 云雾）随音乐起伏的幅度，0 = 完全静止 |
| 有背景图时的动态背景 | 默认 0（让位给照片），调高即"照片 + 云雾"叠加 |
| 音频光晕强度 | 跟着低频鼓点呼吸的柔光，0 = 关闭 |
| 显示天际屏 / 明暗 / 字色 | 背景艺术字层 |
| 显示低频调试表 | 排查用：看背景收到的低频、有没有音频捕获 |

### 歌词

| 项 | 说明 |
|---|---|
| 字号 / 当前行放大倍率 / 行高 | 排版基础 |
| 非当前行的模糊·变暗 | 0 = 不虚化（唱完的行仍会划掉隐藏） |
| 左右留白 | 歌词列的横向留白（%） |
| 使用自定义字体 / 字体 / 作用范围 | 字体规则见上文 |
| 逐字扫光 / 未唱到的字不透明度 / 当前字光晕 | 逐字效果 |
| 间奏等待点 | 关掉则间奏期间不显示 `···` |

### 翻译歌词

| 项 | 说明 |
|---|---|
| 显示翻译歌词 | 是否在当前句下方显示译文 |
| 字号（相对主歌词）/ 不透明度 / 颜色 | 译文样式 |

### 播放控件

| 项 | 说明 |
|---|---|
| 播放区整体大小 | 封面、字号、控件一起缩放的倍率 |
| 播放区整体垂直位置微调 | 正数上移、负数下移（px） |
| 指针不在控件上时变淡 + 变淡后的不透明度 | 默认关闭 |
| 显示连接状态 / 音量条 / 收藏按钮 | 各部件显隐 |

### LX Music 开放 API

| 项 | 说明 |
|---|---|
| 服务器地址 / 端口 | 默认 `127.0.0.1` / `23330` |

## 歌词行为

这一版对歌词做了几处明确的设计取舍，改动相关代码前建议先读这一段。

- **固定左对齐**
  居中和右对齐已删除（连同面板里的「水平对齐」）。整列歌词左缘对齐同一条竖线，
  当前行的缩放原点是**文字左缘**（`16px 50%`），所以放大时不会比其它行"往右偏一点点"。

- **唱完的行会消失**
  缩小 + 模糊，同时一道删除线从文字左缘划到右缘；不透明度在最后 0.45s 内淡到 0，
  线正好在文字消失时抵达末端。线画在**独立覆盖层**里（不随行的模糊一起糊掉），每帧按行的当前
  rect 重新定位，所以滚动、缩放时都贴着文字走。多行歌词每行各划一道。

- **最后一句不收起**
  唱完仍保持放大与高亮——歌到这里就结束了，没有"下一句"需要它让位。

- **换句居中**
  换句滚动走"逐帧跟随"通道而不是一次性动画：目标在行的缩放/译文过渡期间一直在变，
  一次性动画在快歌词下会被下一句打断、残差无人补（实测会停在离中心几十像素处）。

- **空歌词 / 单句歌词**
  API 返回空时清成「没有歌词」；只有一句的占位词不参与 `[ti:]` 归属校验（否则会被误判成别人的词而清屏）。
  重复拉到同一份空歌词不会重绘，所以「没有歌词」不会闪。

## 常见问题

**壁纸连不上 / 一直「连接中」**

确认 LX Music 在播放状态、开放 API 已开启、面板里的地址与端口一致（默认 `127.0.0.1:23330`）；
若 LX 装在另一台机器上，把 `127.0.0.1` 换成那台机器的 IP 并放行端口。

**改了文件，壁纸没变**

WE 不会热重载网页壁纸：右键托盘 →「重新载入壁纸」，或切换一次壁纸。

**封面不显示 / 背景是默认深色**

部分图床不允许跨域取色，封面会退回"只用歌名派生的兜底色"；封面本身仍会显示。
若封面完全不显示，检查 LX 的状态接口是否带 `picUrl`。

**音频律动没反应**

依赖 WE 的音频捕获（`supportsaudioprocessing`），只对 WE 内部播放的声音有效；
面板里「音频光晕强度」默认 0，需要手动调高；可打开「低频调试表」看是否收到低频。

**歌词和歌对不上**

歌词由洛雪按歌名/歌手匹配，源本身可能错配。本项目会校验 `[ti:]`/`[ar:]` 并在不符时清屏重取，
但无法纠正源数据本身的错误。

## 目录结构

```
index/
├─ index.html          壁纸本体（布局 / 歌词 / 播放控件 / WebGL 背景，全部内联）
├─ we-glue.js          壁纸引擎选项桥：用户属性 → CSS 变量、API 地址代理、字体探测、音频频谱
├─ we-glue.css         选项层的样式覆盖（默认值与页面原值逐字相同）
├─ project.json        壁纸引擎属性面板（42 项 / 6 组 + 强调色）
├─ CustomFont.ttf      自定义字体（可选，放进来就优先使用）
├─ preview.jpg         创意工坊缩略图
├─ README.md
└─ tools/              开发期脚本，不参与壁纸运行（详见 tools/README.md）
   ├─ build/           生成工程产物
   ├─ render/          渲染截图（make-preview.js 会覆盖 preview.jpg）
   ├─ setup/           安装 / 字体扫描（均已停用，保留备用）
   └─ probes/          自测脚本（布局、翻页、划线、歌词、居中、滑条）
```

运行时依赖只有前三项：`index.html` 引用同目录的 `we-glue.css` 与 `we-glue.js`。

## 开发与自测

自测脚本都是一句话跑完的探针：起一个临时服务器 → 用无头浏览器打开工程（用桩数据顶掉 LX 接口）
→ 量指标 → 打印结论。需要 Node 18+ 与本机 Edge/Chrome，且必须**非沙箱**运行（Chromium 要用命名管道）。

```bash
node tools/probes/probe.js 1920 1080   # 布局量测
node tools/probes/probe-flip.js        # 封面翻页后是否回到正位
node tools/probes/probe-strike.js      # 唱完那行的划线 / 拖进度条不划线
node tools/probes/probe-lyrics.js      # 焦点行对齐、空歌词、快速切歌跳变
node tools/probes/probe-scroll.js      # 快速换句能否收敛居中、最后一句是否保持高亮
node tools/probes/probe-empty.js       # 单句歌词、"没有歌词"是否闪烁
node tools/probes/probe-bars.js        # 进度条可拖、音量实时下发
```

注意：`tools/render/make-preview.js` 会**覆盖** `preview.jpg`，平时不要随手跑；
只想看效果请用 `node tools/render/render-shot.js`（截图写到临时文件）。

## 更新日志

### 1.2.0

**布局重做**

- 屏幕按中线分左右两半：左半屏播放区、右半屏歌词；控件行不再悬浮在底部
- 播放区改为 Apple Music 式竖排（封面 → 歌名/歌手 → 进度条 → 控件行 → 状态条），尺寸与间距按参照图比例反推，
  封面随窗口缩放，整列靠向中线
- 天际屏层级调整为：背景 < 封面与控件 < 天际屏 < 歌词

**歌词**

- 固定左对齐，删除「水平对齐」（居中 / 左 / 右）及相关的 FLIP 过渡、等待点落点计算
- 唱完的行新增「划掉」效果并淡出隐藏；最后一句唱完保持高亮
- 修复：切歌时歌词偶发不切换（归属校验失败后保留旧画面）
- 修复：洛雪对新歌仍返回上一首歌词时画面残留（现在清成「没有歌词」，并继续重试）
- 修复：只有一句的占位歌词（如「纯音乐，请欣赏」）被误判成"没有歌词"
- 修复：「没有歌词」每 8 秒闪一下（看门狗重复重绘）
- 修复：快速换句时居中失效、整屏上下乱跳（一次性滚动动画被打断后残差无人补）
- 修复：焦点行比其它行向右偏 16px（缩放原点用了盒子边缘而不是文字左缘）

**播放控件**

- 移除液态玻璃整套（棱环 / 彩边 / 指针高光 / 暗纱 / SVG 折射）与对应的 5 个属性
- 控件行改为纯图标三段式：音量 / 上一首·播放·下一首 / 收藏；传输键放大、实心圆角
- 进度条改粗到 9px、去掉圆点滑块（用填充末端的圆角表示位置）
- 修复：进度条拖不动（`pointer-events` 被父级的 `none` 继承）
- 修复：拖动时圆角被 `scaleX` 压扁（改用 `clip-path`）
- 修复：音量拖动一顿一顿（180ms 尾随防抖改为拖动中节流实时下发）
- 新增：换歌时封面绕竖轴翻页；修复翻页结束后封面消失（旧的 `fill: forwards` 动画未撤销）

**工程**

- 开发脚本按用途收进 `tools/`（build / render / setup / probes），新增 `tools/README.md`
- 新增 7 个无头自测脚本，覆盖布局、翻页、划线、歌词归属、居中、滑条

### 1.1 及更早

底部悬浮胶囊式播放条 + 液态玻璃 + 可切换居中/左/右对齐。1.2.0 已整体替换，相关代码不再保留。
